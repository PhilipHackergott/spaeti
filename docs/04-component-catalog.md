# 04 — Component catalog (the central pool in `godot/components/`)

Every visible thing on every screen is one of these. Adding a component = add it here with its contract.
Screens compose; they never restyle. If you find yourself writing a `PanelContainer` with its own stylebox
inside a scene, stop: use a component, or add one here first.

**Three rules this pool enforces**

1. **One look.** Every colour, font size and screen constant lives in `components/theme.gd` (`class_name Palette`)
   and `components/Theme.tres`. A component may not write a raw hex; a scene may not write a stylebox — nor a
   `Color(...)` on a `ColorRect`. A screen that needs a veil or a hairline assigns the token in `_ready()`
   (`($Dim as ColorRect).color = Palette.DIM`); `test_scenes.gd::test_scenes_write_no_colours` greps every
   screen `.tscn` and fails if the word `Color(` reappears. The pool obeys it too: no `.tscn` in
   `components/` writes a colour either, and the tints, the rain, the modal dimmer and the meter's empty
   cell are `Palette` tokens the script assigns in `_ready()`.
2. **Tree-optional.** Components find their own nodes with `get_node_or_null("%Name")` (never `@onready`) and guard
   every tween with `is_inside_tree()`, so `render()` works on an instance that was never added to a tree — which is
   how `tests/unit/test_scenes.gd` exercises them headless.
3. **Art-optional.** Nothing loads a texture directly; everything goes through `Assets.texture(id)`, which returns a
   placeholder of the exact base-pixel size until the art lane's PNG exists. Art lands with **no code change**.

## The pool

| Component | Scene / script (`class_name`) | Contract | Used by |
|---|---|---|---|
| **Palette** | `theme.gd` (`Palette`) | Tokens only, no nodes. Colours (`WOOD_DEEP…NEON_CYAN`, `INK`, `EDGE`, `SCRIM` (title veil) / `DIM` (behind a card) / `RULE` (1-px separator) / `MODAL_DIM` / `METER_EMPTY`, the set’s `TINT_DUSK/DEEP/DAWN` + `NEON_GLOW` + `RAIN` + `RAIN_RECT`, `TEXT`, `GOOD/WARN/BAD`, `SPEAKER`, `TIER`), sizes (`FONT_TINY/SMALL/BODY 16 · FONT_LEAD 20 · FONT_TITLE 50` — Jersey’s measured-clean sizes, docs/01 "Pixel discipline"), layout (`BASE 480×270`, `COUNTER_H/COUNTER_TOP`, `DIALOGUE_RECT` + `DIALOGUE_W_SERVING`, `SERVE_RECT`, `PORTRAIT_CENTRE_X` / `PORTRAIT_CENTRE_X_SERVING` / `PORTRAIT_OVERLAP` / `PORTRAIT_TOP_MIN`), `static var reduce_motion`. Methods: `theme()` (loads Theme.tres and forces EVERY face in it to antialias-off / hinting-none / subpixel-off), `prepare()`, `speaker_colour(id)`, `tier_colour(tier)`, `box(...)->StyleBoxFlat`, `money(float)->"1,80 €"`, `snap(Vector2)`. | everything |
| **Strings** | `strings.gd` (`Strings`) | THE string table — every user-facing word, plus `hud_line(day, queue)` and `summary_sub(...)` so the separators cannot drift between screens. English base, German for the Kiez’s own nouns (Späti · Pfand · Kiez-Trust) and the engine’s weekdays. `tests/unit/test_strings.gd` fails any `.gd` in `scenes/` or `components/` that sets a label to a literal (`.tscn` placeholders are exempt — they are what the editor shows, and `render()` overwrites them). | every screen + component |
| **Theme** | `Theme.tres` | The one Theme: **Jersey 10 at 16** as the default font (Jersey 25 at 50 for `TitleLabel`), plus styleboxes for `Button` (normal/hover/pressed/disabled/focus), `PanelContainer` and `VScrollBar`, and the type variations `DialoguePanel`, `BubblePanel`, `SlotPanel`, `SlotPanelPicked`, `ChoiceButton`, `StepButton` (a zero-padding −/+ so a table row stays exactly one row tall), `TitleButton`, `HudPlate`, `FlatPanel`, `SpeakerLabel`, `SmallLabel`, `TinyLabel`, `LeadLabel`, `TitleLabel`, `TitleSubLabel`. Every box has `anti_aliasing = false`. | every scene root sets `theme` |
| **Fx** | `Fx.tscn` / `fx.gd` (`Fx`) | The feedback layer: `Session.event` (every new log entry, docs/05 §7) → a code-drawn pop on the pixel grid — a coin for `serve`/`tip`, a clink for `pfand`, motes for `arrive`/`upgrade`, a grey puff for `balk`/`ethics`/`raid`. `on_event(entry)`, `play(kind, at)`. No texture, no state: an FX that fails to play may never change a night. Silent under `reduce_motion`. | Night |
| **Assets** | `assets.gd` (`Assets`) | `texture(id)->Texture2D` (real PNG or generated placeholder), `portrait(portrait_id, expression)` — it resolves the EXPRESSION first (an id with neither a PNG nor a `SIZES` entry falls back to `_neutral`, docs/05 §6) so a missing expression keeps the bust's 190×230 footprint instead of collapsing to `FALLBACK_SIZE` —, `is_real(id)`, `size_of(id)` (mirrors `docs/asset-spec.json`; `test_scenes.gd::test_asset_sizes_match_the_spec` reads the spec and fails on any drift), `clear_cache()`. Placeholders: bust silhouette for `char/*`, room for `scene/*`, bottle/box for props, disc for `ui/*` — each in a hashed colour with the id stamped in a built-in 3×5 font. | every component that shows art |
| **MockView** | `mock_view.gd` (`MockView`) | `PRESETS`, `presets()`, `view(preset) -> Dictionary` shaped **exactly** like `Rules.view(state)` (docs/05 §5) for all nine capture presets, with the **same strings** the engine formats (`"Kiez-Trust 62"`, a German weekday from `Rules.WEEKDAY_NAMES`) — `test_scenes.gd::test_mock_view_speaks_the_engines_language` compares the values against `Rules.view()`, so a capture can never show text the engine cannot produce. Mock data only — no rules. | `Screen.apply_capture_preset`, tests |
| **Screen** | `screen.gd` (`Screen`, extends Control) | Base for composed screens. `@export default_preset`, `view()` (Session's when `/root/Session` exists, else the mock — a capture preset always wins), `render(v)` (override), `refresh()`, `dispatch(action)` (Session, else prints), `apply_capture_preset(name)`, signal `request_screen(name)`. | Title, Night, Manage, Summary |
| **PixelPanel** | `PixelPanel.tscn` / `pixel_panel.gd` (`PixelPanel`) | The generic dark translucent box. `@export title`, `@export variation` (`&"DialoguePanel"`, `&"SlotPanel"`, …), `content()`, `add_content(n)`, `clear_content()`. | ad-hoc panels |
| **PixelButton** | `PixelButton.tscn` / `pixel_button.gd` (`PixelButton`) | `extends Button`. `@export icon_id` (through Assets), `@export action: Dictionary` (an engine action), signal `activated(action)` on top of `pressed`. Focus ring from the Theme, so the keyboard works. | every clickable |
| **Meter** | `Meter.tscn` / `meter.gd` (`Meter`) | Icon + label + segmented bar; colourblind-safe (icon + number carry the meaning). `@export icon_id/label_text/value 0..1/fill/segments`, `set_reading(value, text)`. | Hud |
| **ItemSlot** | `ItemSlot.tscn` / `item_slot.gd` (`ItemSlot`) | One SKU as a full-width row: an 18×26 icon well that CLIPS (so a 36-px bottle cannot stretch the row), name, price (coloured by `tier`), stock, badge (till count, or `18` when restricted — the cell always holds its width so the columns line up down the list). `@export sku: Dictionary` (a `view.shelf` entry), `@export count`, signal `picked(sku_id)`; click or `ui_accept`, out-of-stock slots dim and do not emit. 28 px tall. | Shelf |
| **Shelf** | `Shelf.tscn` / `shelf.gd` (`Shelf`) | The stock LIST: one ItemSlot per SKU, registry order, inside the ServePanel’s scroll window. (It was a 5-wide grid of 42-px tiles; at the pool’s one text size a tile that narrow could print a name **or** a price, never both — and the shelf is 17 SKUs, 23 once the modules land.) `set_items(items, counts := {})`, `set_counts(counts)`, `slot_for(sku_id)`, signal `picked(sku_id)`. Re-uses slots between renders. | ServePanel |
| **Till** | `Till.tscn` / `till.gd` (`Till`) | The ring-up tray. `set_lines/add_sku/set_pfand/set_pfand_rate/clear/counts/total/give_list`; signals `ring_up(give, pfand_bottles)`, `pfand_toggled`, `waved_off`, `line_removed`. Shows at most `MAX_ROWS` lines + a "+N more" row + the Pfand line, which prices the deposit from `pfand_rate` (fed from `view.pfand_rate`; it defaults to **0**, because a component may not reach into the engine for a fallback and a tray quoting 0,00 is a wiring bug you can see); "Ring up" disables when the tray is empty. | ServePanel |
| **ServePanel** | `ServePanel.tscn` / `serve_panel.gd` (`ServePanel`) | Coffee Talk’s brew panel: slides in over the right half (`SHOWN_X 228 → HIDDEN_X 482`), header names who is waiting, the Shelf in a scroll window above, the Till below. `render(view)` also **scrolls the shelf to the SKU the customer asked for**, so what you need is never three rows down. `open(instant)`, `close(instant)`, `till()`, `preload_picks(sku_ids, pfand_bottles)` (capture presets); signals `serve(action)` — a ready-made `serve_active` — `waved_off`, `closed`. | Night |
| **DialogueBox** | `DialogueBox.tscn` / `dialogue_box.gd` (`DialogueBox`) | The centrepiece: coloured speaker name, white typewriter body (`chars_per_second`), a blinking code-drawn ▾ (a `Polygon2D`: no pixel face in the pack has a ▾ glyph), choices stacked just above the box. `show_dialogue(view.dialogue, instant)` (idempotent: the same speaker + lines + choices re-sent is ignored, so the per-frame render never restarts the typewriter), `show_final(d)` (capture: last line + choices), `advance()`, `clear()`, `is_typing()`; signals `choice(index)`, `advanced`, `finished`. Click or Space advances. | Night |
| **Portrait** | `Portrait.tscn` / `portrait.gd` (`Portrait`) | The bust, placed at its **native** size on integer pixels (never scaled) and anchored by its **bottom-centre**: `place_behind(counter_edge_y, centre_x)` seats it against the counter’s real occlusion line with `PORTRAIT_OVERLAP` px behind the wood. Bottom-centre, not a spec rectangle — shipped art is narrower than its placeholder box (`char/you_neutral` is 155 against a 190 spec), so a left-anchored bust drifts off centre. `overlap_behind()`, `@export portrait_id/expression/breathe`, `set_from_active(view.active)`, `slide_in()`, `slide_out()`; idle breathing is a stepped 1-px bob and stops under `Palette.reduce_motion`. | Night |
| **WantBubble** | `WantBubble.tscn` / `want_bubble.gd` (`WantBubble`) | Icon + name + price + optional line, with a code-drawn tail. `set_want(view.active.want, said := "")`, `@export line`. | Night |
| **SceneLayers** | `SceneLayers.tscn` / `scene_layers.gd` (`SceneLayers`) | The set, in draw order: `Backdrop → NeonGlow → Rain → Characters → Counter → Tint` — the rain is **on the glass**, inside `Palette.RAIN_RECT` (the door/window opening) and behind everyone, not falling through the shop. `@export backdrop_id/counter_id/night_progress/raining/rain_drops/neon`, `set_time(0..1)` (dusk → deep night → cold pre-dawn), `counter_top()`, **`mount(node)`** — puts a bust in the character slot *behind the counter*; it uses `reparent()` so the node keeps its `owner` (and therefore its `%unique name`). The counter art is always flush with the bottom of the frame whatever its height. Rain is seeded (1337) so a capture is reproducible; rain and neon flicker stop under `reduce_motion`. | Night, Manage, Summary |
| **Hud** | `Hud.tscn` / `hud.gd` (`Hud`) | Corner cluster on two low-alpha plates: clock / cash / Pfand + "Night 3 · 2 waiting" top-left, two Meters top-right. (No weekday: at one text size the corner cannot hold it and still leave the other corner to the meters — the weekday is on the Manage title and the Summary sub-line.) `render(view)`, `set_compact(on)` hides the right plate **and** the night/queue tail while the serve panel owns that half. | Night |
| **TallyRow** | `TallyRow.tscn` / `tally_row.gd` (`TallyRow`) | One P&L line. `@export row_label/value/kind` (`in`/`out`/`total`/`plain` → sign, colour and size), `play(delay, duration)` counts the number up. | SummaryTally |
| **SummaryTally** | `SummaryTally.tscn` / `summary_tally.gd` (`SummaryTally`) | Builds the rows from a NightSummary: Umsatz, Trinkgeld, Einkauf, Miete+Strom, Pfand, rule, Gewinn. `set_summary(s)`, `play()` (staggered). | Summary |
| **ManageBoard** | `ManageBoard.tscn` / `manage_board.gd` (`ManageBoard`) | The pre-opening board: one row per SKU (stock, wholesale cost, restock +, price coloured from the engine’s `tier` (`view.manage.restock_options[].tier`) against its fair band, price −/+, the band itself), the module list, and "Open up". `render(view)`; signals `action(Dictionary)` (`restock` / `set_price` / `buy_upgrade`) and `open_night()`. Rows are built at runtime; the shell is in the `.tscn`. The scroll window is sized to `ROWS_VISIBLE` **measured** rows (`_fit_scroll_to_whole_rows`), never a hand-tuned constant — that is what stops the list slicing a row in half when the font changes. | Manage |
| **Modal** | `Modal.tscn` / `modal.gd` (`Modal`) | The one overlay shell: dimmer, centred frame, title, close button, Esc. `@export title/closable`, `open()`, `close_modal()`, `content()`, `add_content(n)` (reparents, keeping `owner`), `clear_content()`; signal `closed`. | Manage, Title (settings) |
| **Transition** | `Transition.tscn` / `transition.gd` (`Transition`) | Full-frame fade. `cover()`, `reveal()`, `cover_then(Callable)`; signals `covered`, `revealed`. | Main |

## The screens (`godot/scenes/`)

| Scene | Root | What it composes | Presets |
|---|---|---|---|
| `Main.tscn` / `main.gd` | Control | The shell: `%Screens` host + `Transition`. `show_screen(name, instant)`, `apply_capture_preset(p)` (maps preset → screen), `PRESET_SCREEN`. Boots to Title. | all (delegates) |
| `Title.tscn` / `title.gd` | Screen | `scene/title` art + a gradient scrim + wordmark + vertical menu (Neues Spiel / Fortsetzen (disabled) / Einstellungen → Modal / Beenden). | `title` |
| `Night.tscn` / `night.gd` | Screen | SceneLayers (Portrait mounted into its character slot) + Hud + Fx + WantBubble + DialogueBox + ServeToggle + ServePanel. Turns choices into `resolve_beat`/`resolve_vignette`, the till into `serve_active`, "Wave off" into `skip_active`. Ends the night itself: at `night_progress ≥ 1` with a clear counter it dispatches `close_night`, and on `phase == "summary"` it requests the summary screen (each latched once). When no beat is pending it shows the customer's plain order line (presentation only). Opening the serve panel steps the bust left (`PORTRAIT_CENTRE_X_SERVING`), narrows the dialogue box and stands the want bubble down, so nothing is covered. | `empty_counter`, `customer_at_counter`, `dialogue_choice`, `serving`, `pfand`, `late_night` |
| `Manage.tscn` / `manage.gd` | Screen | SceneLayers (dimmed by the Modal) + Modal + ManageBoard mounted into it. | `manage` |
| `Summary.tscn` / `summary.gd` | Screen | SceneLayers + dim + centred card with SummaryTally + Weiter (`advance_day`). | `summary` |

Capture: `node tools/godot/shot.mjs --scene res://scenes/Night.tscn --out shots/x.png --preset customer_at_counter`.
Play: `node tools/godot/play.mjs` drives the whole pool for real — New game → restock → Open up → pick → Ring up
→ a story beat → Wave off → 06:00 → Summary → night 2 — and saves a frame per step (`godot/tools/playthrough.gd`).
Test: `node tools/godot/test.mjs --filter scenes` loads and instantiates every component, applies every preset to
every screen, and checks the mock read-model against the docs/05 §5 key list.
